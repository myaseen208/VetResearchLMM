# Example 1.2.3: comparing two drugs with herds as experimental units

Change in packed cell volume (PCV, %) of seven animals in each of four
herds; Berenil was given to two herds and Samorin to the other two, so
herds are nested in drug (Table 1.2.3 and Appendix A of the book). New
in version 2.0.0.

## Usage

``` r
ex123
```

## Format

A data frame with 28 rows and 3 variables:

- herd:

  herd: 1 to 4.

- drug:

  drug: `Berenil` or `Samorin`.

- PCVdif:

  change in PCV.

## Source

Duchateau, L., Janssen, P. and Rowlands, G. J. (1998). *Linear Mixed
Models. An Introduction with Applications in Veterinary Research*.
International Livestock Research Institute, Nairobi. Appendix A.
