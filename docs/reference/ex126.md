# Example 1.2.6: variation in ELISA data

Optical density (OD) of an ELISA for four untreated animals, measured at
11 times with two blood samples each time: a random effects model for
the sources of variation (Table 1.2.6 and Appendix A of the book). New
in version 2.0.0.

## Usage

``` r
ex126
```

## Format

A data frame with 88 rows and 4 variables:

- time:

  time point: 1 to 11.

- replicat:

  blood sample at the time point: 1 or 2.

- anim_id:

  animal: 1 to 4.

- OD:

  optical density.

## Source

Duchateau, L., Janssen, P. and Rowlands, G. J. (1998). *Linear Mixed
Models. An Introduction with Applications in Veterinary Research*.
International Livestock Research Institute, Nairobi. Appendix A.
