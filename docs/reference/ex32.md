# Example 3.2: weaning weights of lambs by breed and sire (part of the data)

Weaning weight (kg) of lambs of six breeds, with sex and age at weaning,
for the complete offspring of a few sires per breed. The book prints
only this part of the data, so the analyses of Example 3.2 run but do
not reproduce the printed results.

## Usage

``` r
ex32
```

## Format

A data frame with 65 rows and 5 variables:

- breed:

  breed: 1 to 6.

- sire_id:

  sire (nested in breed).

- sex:

  sex: `F` or `M`.

- agew:

  age at weaning (days).

- Ww:

  weaning weight.

## Source

Duchateau, L., Janssen, P. and Rowlands, G. J. (1998). *Linear Mixed
Models. An Introduction with Applications in Veterinary Research*.
International Livestock Research Institute, Nairobi. Appendix A.
